# Comeback OS

## Purpose

A personal, offline Windows training and recovery tool for a basketball player rehabilitating a right forearm injury. The first action is to see the prescribed session and resume it using one hand. The user supplied the curriculum, safety thresholds and visual identity.

## Audience and environment

One athlete, at a PC in a 2 × 2 m dorm training space. The athlete may be standing away from the display with a load in the left hand. Workouts, interval sounds and exercise movement guides must run offline. The surgeon determines when right-arm loading can resume.

## Brand commitments

Egyptian Blue, Stone Blue, slate navy, off-white and a Scarlet warning channel. Reference Whoop, Linear and Nike Training Club for restraint, hierarchy and athletic clarity. Stroke icons, monospace measurements and an original composition. No neon gradients.

## Platform

Windows desktop, Electron with React and TypeScript. The dashboard uses a sidebar, a high-legibility session lead and readiness alongside the prescription. The workout player puts the current set and timer within a single keyboard-controlled surface.
